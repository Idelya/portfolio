# Content

The owner provides content; agents structure, translate and polish it. **Agents never invent facts**
about the owner (employers, dates, technologies used, achievements, contact data). Use `TODO(content)`
placeholders and add the gap to the checklist below.

## Content checklist

Status legend: ⬜ missing · 🟨 draft · ✅ final (both locales)

- ⬜ Full name as it should appear: "Anna Papros-Matejuk"

- ⬜ Short bio (≤ 80 words) and long bio (≤ 250 words)
- ⬜ Location / remote availability
- ⬜ Availability status (open to work? freelance?)
- ⬜ Professional photo or avatar (also used for OG image)

### Contact and links

### Projects

### Other

- ⬜ Testimonials (optional)

## Writing guidelines

- **Tone:** professional, confident, warm; first person ("I build…"). No buzzword stacking.
- **Scannable:** short paragraphs, achievement-focused bullets with numbers where possible.
- **Both locales are equal.** Polish is not a machine translation of English; it should read naturally.
  Agents may draft a translation, but the owner approves it.
- **SEO:** the name and job title appear naturally in the hero, page title and meta description.
- **Alt text:** describe what matters in the image, localized, ≤ 125 chars.
- **Images:** source files in `public/images/`, at least 2× display size, WebP/AVIF served via `next/image`.
