# Portfolio

Clean personal portfolio starter built with [Next.js](https://nextjs.org).

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Edit `app/page.tsx` to customize the main page.

## Project Structure

- `app/layout.tsx` - global layout and metadata
- `app/page.tsx` - main page content
- `app/globals.css` - global styling
- `public/` - static assets (only keep what is used)

## Scripts

- `npm run dev` - start development server
- `npm run build` - create production build
- `npm run start` - run production server
- `npm run lint` - run ESLint checks

## Deploy

Deploy on Vercel or any platform that supports Node.js.
