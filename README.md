# Anna Papros-Matejuk — Portfolio

Personal portfolio of Anna Papros-Matejuk, software developer. A fast, accessible, bilingual (EN/PL)
site: an illustrated, scroll-driven fairy-tale scene on the home page, with clickable objects leading
to clear content pages for recruiters and clients.

## Getting started

Requires Node.js 26 (version pinned in `.nvmrc`).

```bash
nvm use
npm install
npm run dev     # http://localhost:3000
```

Other scripts: `npm run build`, `npm run lint`.
